# Local conference assets

The active institution logos are `logos/iitr.png`, `logos/csir-iip.png` and `logos/hkust.png`, copied from the organizer-supplied PNGs in the root `assets/logos/` folder. `src/content/about.json` supplies their paths and alt text for the identity band, About section, footer and countdown page. Original colors and aspect ratios are preserved, with a white backing for use on dark backgrounds. The old logo SVGs are unused placeholders.

Portrait and hospitality image placeholders live in `public/placeholders/`. Replace these only with approved assets and keep assets local to the site.
